# 🐔💥 Chicken Run

เกมปาร์ตี้มัลติเพลเยอร์แบบเรียลไทม์บนเบราว์เซอร์ เล่นได้ 2–8 คนต่อรอบ วิ่งไปข้างหน้า หลบรถ ผลักเพื่อนให้โดนรถ แล้วไปให้ถึงเส้นชัยก่อนกล้องจะไล่ทัน

เล่นได้ทั้งบนคอมและมือถือ แค่ต่อ Wi-Fi วงเดียวกันแล้วเปิดลิงก์ ไม่ต้องติดตั้งแอป

## วิธีเล่น

- วิ่งขึ้นไปข้างหน้า ข้ามถนนที่มีรถและรถบรรทุกวิ่งสวนไปมา
- **กล้องจะเลื่อนขึ้นเรื่อย ๆ และเร็วขึ้นตามเวลา** ถ้าตกขอบล่างของจอนานเกิน 1.5 วินาที (หรือตกลึกเกินไป) จะตกรอบ
- กด **DASH** เพื่อพุ่งไปข้างหน้าประมาณ 2 ช่อง (คูลดาวน์ 2 วินาที) ถ้าพุ่งชนเพื่อน เพื่อนจะกระเด็นและมึนไปครู่หนึ่ง
- ถ้าเพื่อนโดนรถชนภายใน 2 วินาทีหลังจากเราผลัก จะนับเป็น "อุบัติเหตุ" ของเรา ใครทำเยอะสุดได้ฉายา **ไก่อันตรายที่สุด** 😈

### จบรอบเมื่อ

- มีคนถึงเส้นชัย แล้วนับถอยหลังให้คนที่เหลืออีก 10 วินาที
- เหลือไก่รอดอยู่ตัวเดียว (กรณีเริ่มรอบด้วย 2 คนขึ้นไป) คนนั้นชนะในฐานะ **LAST CHICKEN STANDING**
- ไก่ตายหมดทุกตัว

หน้าสรุปผลจะแสดงอยู่ 8 วินาที แล้วรอบใหม่จะเริ่มเองอัตโนมัติ

## ปุ่มควบคุม

| | คอมพิวเตอร์ | มือถือ |
|---|---|---|
| เดิน | `WASD` หรือ ปุ่มลูกศร | แตะค้างที่จอแล้วลาก (จอยสติ๊กเสมือน) |
| Dash | `Space` / `Shift` / `J` / `K` | ปุ่ม **DASH** |
| เปลี่ยนคนที่ดู (ตอนตายหรือรอรอบ) | `Space` / `Enter` / `←` `→` / `Tab` | แตะจอ |

## การติดตั้งและรัน

ต้องมี [Node.js](https://nodejs.org/) (แนะนำเวอร์ชัน 18 ขึ้นไป)

```bash
npm install
```

```bash
npm start
```

เซิร์ฟเวอร์จะรันที่พอร์ต `3000` และพิมพ์ลิงก์ให้ดูในเทอร์มินัล:

```
  🐔💥 CHICKEN RUN server running
  Local:   http://localhost:3000
  Network: http://192.168.x.x:3000   <- open this on phones (same Wi-Fi)
```

- เปิด `Local` บนเครื่องตัวเอง
- ให้เพื่อนเปิดลิงก์ `Network` บนมือถือหรือคอมที่ต่อ Wi-Fi วงเดียวกัน (ในเมนูของเกมมีปุ่มคัดลอกลิงก์ให้ด้วย)

ถ้าต้องการเปลี่ยนพอร์ต ให้ตั้งตัวแปร `PORT` ก่อนรัน:

```bash
PORT=8080 npm start
```

> ถ้าเพื่อนเข้าลิงก์ `Network` ไม่ได้ ให้เช็กว่า Firewall ของ Windows อนุญาตให้ Node.js รับการเชื่อมต่อในเครือข่ายส่วนตัวแล้ว

## ระบบห้องเล่น

- เซิร์ฟเวอร์มี **ห้องเดียว** ใช้ร่วมกันทุกคน รับได้สูงสุด 16 คน
- แต่ละรอบเล่นได้ 8 คน คนที่เกินจะเข้าไปดูในฐานะผู้ชมและได้เล่นรอบถัดไป
- ถ้าเข้ามาระหว่างนับถอยหลัง 3 วินาทีก่อนเริ่ม จะได้เข้าร่วมรอบนั้นเลย
- ตั้งชื่อไก่ได้ไม่เกิน 12 ตัวอักษร (ถ้าไม่ใส่จะได้ชื่อ `Chick<เลข>`)

## โครงสร้างโปรเจกต์

```
server.js          เซิร์ฟเวอร์ HTTP (ส่งไฟล์ใน public/) + WebSocket คุมเกมทั้งหมด
public/
  index.html       หน้าเกม เมนู หน้ารอ หน้าสรุปผล
  shared.js        โค้ดจำลองเกมที่ใช้ร่วมกันทั้งเซิร์ฟเวอร์และเบราว์เซอร์ (ค่าคงที่, สร้างแมพ, ฟิสิกส์)
  game.js          ฝั่งไคลเอนต์: UI, เน็ตเวิร์ก, client-side prediction, วาดภาพ, รับอินพุต
  art.js           วาดตัวละครและฉากด้วย canvas ล้วน ๆ (ไม่มีไฟล์รูป)
  audio.js         เสียงสังเคราะห์ด้วย Web Audio API (ไม่มีไฟล์เสียง)
  style.css        สไตล์ของ UI
```

### หลักการทำงานโดยย่อ

- **เซิร์ฟเวอร์เป็นผู้ตัดสิน (authoritative)** จำลองเกมที่ 30 ticks/วินาที รับอินพุตจากผู้เล่น คำนวณการชน การตาย และส่ง snapshot กลับไปทุก tick
- **แมพสร้างจาก seed** ทั้งสองฝั่งเรียก `CR.buildMap(seed)` ได้แมพเดียวกัน ตำแหน่งรถเป็นฟังก์ชันของเวลาล้วน ๆ จึงไม่ต้องส่งข้อมูลรถผ่านเน็ต
- **ไคลเอนต์ทำนายการเคลื่อนที่ล่วงหน้า** ด้วย `CR.stepPlayer` ตัวเดียวกับเซิร์ฟเวอร์ แล้วแก้ตำแหน่งตาม snapshot ที่ได้รับ ทำให้ควบคุมได้ลื่นแม้มีดีเลย์

### ปรับจูนเกม

ค่าเกือบทั้งหมดอยู่ในออบเจกต์ `C` ใน [public/shared.js](public/shared.js) เช่น

| ค่า | ความหมาย |
|---|---|
| `SPEED` | ความเร็วเดินของไก่ (ช่อง/วินาที) |
| `DASH_SPEED`, `DASH_TIME`, `DASH_CD` | ความเร็ว ระยะเวลา และคูลดาวน์ของ Dash |
| `KNOCK`, `STUN` | แรงกระเด็นและเวลามึนเมื่อโดนผลัก |
| `CAM_V0`, `CAM_ACC` | ความเร็วเริ่มต้นและอัตราเร่งของกล้อง |
| `DANGER_TIME` | เวลาที่อยู่ใต้ขอบกล้องได้ก่อนตกรอบ |
| `FINISH_GRACE` | เวลาที่เหลือให้คนอื่นหลังมีคนเข้าเส้นชัย |
| `MAX_PLAYERS` | จำนวนผู้เล่นต่อรอบ |

ลำดับด่านกำหนดใน `MVP_SEQUENCE` และรูปแบบเลนแต่ละชุดอยู่ใน `CHUNKS`
